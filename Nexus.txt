NexusFlow – Modulare Organisations- & Workflow-PWA
Dieses Paket enthält den vollständigen, typensicheren Quellcode deiner installierbaren Progressive Web App (PWA) auf Basis von Vite + React + TypeScript + Tailwind CSS + IndexedDB.

Schnellstart im Terminal (lokal oder in Antigravity)
Lege die unten aufgeführten Dateien in deinem Projektordner an (oder übergib dieses Dokument direkt an deinen Coding-Agenten mit dem Hinweis „Lege alle Dateien exakt wie dokumentiert an und führe npm install && npm run dev aus“) und starte die App mit:
npm install
npm run build
npm run dev
    • Standard-Ansicht (Smartphone-Hochkant / Ziehharmonika-Fokus): http://localhost:5173/
    • Galaxy Z Flip 7 Frontdisplay-Widget (Direktstart): http://localhost:5173/?mode=cover
    • Globaler Sprach- & KI-Shortcut: Alt + S

1. Architektur-Gesetze & Projekt-Konfiguration
SPEC.md
# SPEC.md – Feste Architektur-Gesetze (NexusFlow PWA)

## 1. Visuelles Design-System (Anthrazit & Petrol)
- **Hintergrund Hauptfläche (`bgMain`):** `#181A1B`
- **Karten & Container (`bgCard`):** `#24292E`
- **Unterpunkte & Listen-Elemente (`bgSub`):** `#2F363D`
- **Primär-Akzent (`accentPrimary`):** `#0A9396`
- **Highlight-Akzent (`accentHighlight`):** `#14B8A6`
- **Text Primär / Meta:** `#F8F9FA` / `#9CA3AF`
- **KI-Indikator:**
  - **Vorne (Mobil / Alltag):** Ausschließlich ein dezenter `6px` roter Punkt (`#EF4444`), antippbar zum Bestätigen. Keine überladenen Metadaten-Fußzeilen unter kompakten Tasks.
  - **Hinten (Desktop-Backoffice):** Volles „KI-bearbeitet“-Badge inklusive Änderungszeitpunkt, Quelle und Undo-/Verschiebe-Option.
- **Abhak-Regel:** Erledigte Tasks und Einkäufe werden **niemals durchgestrichen**, damit Maße, Bezeichnungen und Mengen jederzeit lesbar bleiben.

## 2. Zwei-Schichten-Navigation
### Schicht 1: Front-Ansicht (Mobil Hochkant `max-w-md` / Ziehharmonika-Fokus)
1. **Domänen-Umschalter:** `?? ARBEIT` (Pizza Bandit, Bäckerei) vs. `? PRIVAT` (Smart Home, Gewohnheiten, Alltag).
2. **Ziehharmonika-Auswahl:** Sobald ein Projekt aktiv ist, zieht sich die Projektliste zu einer schmalen Breadcrumb-Leiste zusammen.
3. **5 feste Reiter pro Projekt:**
   - `Tasks` (inkl. „Checkliste für Einsatz zurücksetzen“ & 1-Klick-Übertrag in den Einkaufswagen)
   - `Arbeitserklärungen` (Schritt-für-Schritt-Abläufe, Metadaten nur im aufgeklappten Zustand)
   - `Allgemeine Infos` (Referenzwerte + IndexedDB Datei-/Foto-/PDF-Anhänge)
   - `Einkaufswagen` (inkl. ausklappbarem Beschaffungs-Check)
   - `? Extras` (Rendert isolierte Steckkarten-Plugins des jeweiligen Projekts)
4. **Flip-7-Cover-Modus (`?mode=cover`):** Quadratisches 3.4"-Widget mit großem Petrol-Mikrofon-Button und den Top 3 offenen Tasks zum Sofort-Abhaken.

### Schicht 2: Backoffice-Zentrale (Desktop `max-w-6xl` – 4 Hauptbereiche)
1. `? Auswertung & Historie` (POS Event-Abrechnungen mit CSV/TSV-Export, KI-Protokoll mit Undo/Move, Selbst-Check-Verlauf, Aktenschrank/Archiv)
2. `? Planung & Automatisierung` (4 Tagesblöcke, KI-Tagesstrukturierung, Großprojekt-Etappenrechner, `.ics`-Export)
3. `? Add-on Zentrale` (Plugin-Verwaltung je Projekt + Schnell-Timer/Notizrechner & Teigrechner)
4. `?? System & Schnittstellen` (Gemini API-Key, JSON-Schema, Flip-7-Direktstart, Home Assistant Webpage-Card & Webhook, IndexedDB Voll-Backup)

## 3. Strikte Plugin-Isolation (`src/plugins/`)
- Jedes Zusatz-Werkzeug liegt isoliert in `src/plugins/`.
- Plugins verändern niemals direkt den globalen App-Kern, sondern kommunizieren ausschließlich über typisierte Callbacks (`PluginContextProps`) und `project.customMeta`.

import { get, set } from 'idb-keyval';
import { AppStateSnapshot } from '../types';

const IDB_STATE_KEY = 'nexusflow_pwa_v1_state';
const LS_FALLBACK_KEY = 'nexusflow_pwa_v1_fallback';

export const formatNow = (): string => {
  const now = new Date();
  const d = String(now.getDate()).padStart(2, '0');
  const m = String(now.getMonth() + 1).padStart(2, '0');
  const y = now.getFullYear();
  const hh = String(now.getHours()).padStart(2, '0');
  const mm = String(now.getMinutes()).padStart(2, '0');
  return `${d}.${m}.${y}, ${hh}:${mm} Uhr`;
};

export async function loadPersistedState(
  defaultSeed: AppStateSnapshot
): Promise<AppStateSnapshot> {
  try {
    const stored = await get<AppStateSnapshot>(IDB_STATE_KEY);
    if (stored && Array.isArray(stored.projects) && stored.projects.length > 0) {
      return {
        ...defaultSeed,
        ...stored
      };
    }
  } catch {
    try {
      const raw = localStorage.getItem(LS_FALLBACK_KEY);
      if (raw) {
        const parsed = JSON.parse(raw) as AppStateSnapshot;
        if (parsed && Array.isArray(parsed.projects)) {
          return { ...defaultSeed, ...parsed };
        }
      }
    } catch {
      // Fallback auf Seed
    }
  }
  return defaultSeed;
}

export async function savePersistedState(snapshot: AppStateSnapshot): Promise<void> {
  try {
    await set(IDB_STATE_KEY, snapshot);
  } catch {
    try {
      localStorage.setItem(LS_FALLBACK_KEY, JSON.stringify(snapshot));
    } catch {
      // Speicherlimit erreicht
    }
  }
}

export function downloadStateBackupJson(snapshot: AppStateSnapshot): void {
  const blob = new Blob([JSON.stringify(snapshot, null, 2)], {
    type: 'application/json;charset=utf-8'
  });
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = `nexusflow-backup-${new Date().toISOString().slice(0, 10)}.json`;
  a.click();
  URL.revokeObjectURL(url);
}

import { EventSalesLog, Project } from '../types';

export function exportEventSalesToCsv(logs: EventSalesLog[]): void {
  const header = [
    'Datum_Uhrzeit',
    'Event_Name',
    'Pizzen_Gesamt',
    'Umsatz_Brutto_EUR',
    'Wareneinsatz_EUR',
    'Rohertrag_EUR',
    'Feuerwehrauto_Fonds_Trinkgeld_EUR',
    'Sorten_Aufschluesselung'
  ];

  const rows = logs.map((l) => {
    const breakdown = l.items.map((i) => `${i.name}: ${i.count}x`).join(' | ');
    return [
      `"${l.timestamp}"`,
      `"${l.eventName.replace(/"/g, '""')}"`,
      l.totalPizzas,
      l.grossRevenue.toFixed(2).replace('.', ','),
      l.cogsTotal.toFixed(2).replace('.', ','),
      l.grossProfit.toFixed(2).replace('.', ','),
      l.firetruckTipFund.toFixed(2).replace('.', ','),
      `"${breakdown}"`
    ].join(';');
  });

  const csvContent = '\uFEFF' + [header.join(';'), ...rows].join('\r\n');
  const blob = new Blob([csvContent], { type: 'text/csv;charset=utf-8' });
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = `pizza-bandit-abrechnungen-${new Date().toISOString().slice(0, 10)}.csv`;
  a.click();
  URL.revokeObjectURL(url);
}

export async function copyEventSalesAsTsvForSheets(logs: EventSalesLog[]): Promise<boolean> {
  const header = [
    'Zeitstempel',
    'Event',
    'Pizzen',
    'Umsatz (€)',
    'Wareneinsatz (€)',
    'Rohertrag (€)',
    'Feuerwehrauto-Fonds (€)',
    'Sorten'
  ].join('\t');

  const lines = logs.map((l) =>
    [
      l.timestamp,
      l.eventName,
      l.totalPizzas,
      l.grossRevenue.toFixed(2).replace('.', ','),
      l.cogsTotal.toFixed(2).replace('.', ','),
      l.grossProfit.toFixed(2).replace('.', ','),
      l.firetruckTipFund.toFixed(2).replace('.', ','),
      l.items.map((i) => `${i.name} (${i.count}x)`).join(', ')
    ].join('\t')
  );

  const tsv = [header, ...lines].join('\n');
  try {
    await navigator.clipboard.writeText(tsv);
    return true;
  } catch {
    const ta = document.createElement('textarea');
    ta.value = tsv;
    document.body.appendChild(ta);
    ta.select();
    document.execCommand('copy');
    document.body.removeChild(ta);
    return true;
  }
}

export function exportScheduledTasksToIcs(projects: Project[]): number {
  const blockTimes: Record<string, { start: string; end: string }> = {
    morning: { start: '063000', end: '083000' },
    focus: { start: '100000', end: '120000' },
    errands: { start: '150000', end: '163000' },
    evening: { start: '183000', end: '193000' }
  };

  const todayCompact = new Date().toISOString().slice(0, 10).replace(/-/g, '');
  const lines = [
    'BEGIN:VCALENDAR',
    'VERSION:2.0',
    'PRODID:-//NexusFlow//Modular Workflow PWA//DE'
  ];

  let count = 0;
  projects
    .filter((p) => !p.archived)
    .forEach((proj) => {
      proj.tasks.forEach((t, idx) => {
        if (!t.dayBlock || t.completed) return;
        const slot = blockTimes[t.dayBlock] || blockTimes.focus;
        count++;
        lines.push(
          'BEGIN:VEVENT',
          `UID:nexusflow-${t.id}-${idx}@local`,
          `DTSTAMP:${todayCompact}T060000`,
          `DTSTART:${todayCompact}T${slot.start}`,
          `DTEND:${todayCompact}T${slot.end}`,
          `SUMMARY:[${proj.name}] ${t.title}`,
          `DESCRIPTION:Prioritaet: ${t.priority} | Dauer: ${t.estimatedMinutes} Min.`,
          'END:VEVENT'
        );
      });
    });

  lines.push('END:VCALENDAR');
  const blob = new Blob([lines.join('\r\n')], { type: 'text/calendar;charset=utf-8' });
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = 'nexusflow-tagesplan.ics';
  a.click();
  URL.revokeObjectURL(url);
  return count;
}

export const enforceMaxSixWords = (str: string, fallback = 'Neuer Eintrag'): string => {
  if (!str || typeof str !== 'string') return fallback;
  const words = str.trim().replace(/\s+/g, ' ').split(' ');
  return words.length <= 6 ? words.join(' ') : words.slice(0, 6).join(' ');
};

export function buildLocalFallbackPlan(
  rawText: string,
  defaultProjectId: string
): StructuredAiResponse {
  const segments = rawText
    .split(/;|\s+(?:außerdem|zusätzlich|und\s+ergänze|und\s+erstelle|und\s+füge|und\s+lege|und\s+notiere|und\s+packe)\s+/i)
    .map((s) => s.trim())
    .filter(Boolean);

  const actions: StructuredAiActionPlan[] = segments.map((seg) => {
    const lower = seg.toLowerCase();
    let targetProjectId = defaultProjectId || 'proj-foodtruck';

    if (/(bäckerei|sauerteig|mehl|dinkel|schwaden|backstube)/i.test(lower)) {
      targetProjectId = 'proj-baeckerei';
    } else if (/(pizza|bandit|anhänger|tsa|auszug|saladette|shelly.*blaulicht|eurobox|gas|ofen)/i.test(lower)) {
      targetProjectId = 'proj-foodtruck';
    } else if (/(smart home|zigbee|proxmox|home assistant|sensor|vlan|shelly)/i.test(lower)) {
      targetProjectId = 'proj-smarthome';
    } else if (/(gewohnheit|spaziergang|routine|mobilität|wasser)/i.test(lower)) {
      targetProjectId = 'proj-gewohnheiten';
    } else if (/(alltag|haushalt|steuer|winterreifen|siebträger)/i.test(lower)) {
      targetProjectId = 'proj-alltag';
    }

    let actionType: AiActionType = 'ADD_TASK';
    if (/(einkaufswagen|kaufe|säcke|paar|rollen|set|pakete|bestell)/i.test(lower)) {
      actionType = 'ADD_CART_ITEM';
    } else if (/(arbeitserklärung|quellstück|1\.|ablauf)/i.test(lower)) {
      actionType = 'UPDATE_EXPLANATION';
    } else if (/(allgemeine info|hinweis:|notiere.*info|firmware)/i.test(lower)) {
      actionType = 'ADD_INFO';
    }

    const cleanTitle = seg
      .replace(/^(packe|ergänze|erstelle|füge|lege|notiere)\s+/i, '')
      .replace(
        /bei der bäckerei|in der bäckerei|bei pizza bandit|bei smart home|im alltag|bei gewohnheiten|in den einkaufswagen|unter allgemeine infos/gi,
        ''
      )
      .split(/[:–-]/)[0]
      .trim();

    const shortCheckableTitle = enforceMaxSixWords(cleanTitle, 'Neuer KI-Punkt');
    const colonParts = seg.split(':');
    const detailedExplanation =
      colonParts.length > 1 ? colonParts.slice(1).join(':').trim() : seg;
    const qtyMatch = seg.match(/(\d+\s*(?:Säcke|Paar|Pakete|Kartons|Rollen|Set|Stück|kg|m|L))/i);

    return {
      actionType,
      targetProjectId,
      shortCheckableTitle,
      detailedExplanation,
      quantityOrMeasure: qtyMatch ? qtyMatch[1] : '1x',
      estimatedPrice: '',
      changeFooterNote: 'Per KI-Sprachbefehl einsortiert',
      estimatedMinutes: 25,
      priority: /(dringend|gas|sicherheit|bremse)/i.test(lower) ? 'Hoch' : 'Mittel'
    };
  });

  return {
    summary: `${actions.length} Aktion(en) erkannt und zugeordnet.`,
    actions
  };
}

export async function routeVoiceCommand(
  rawText: string,
  apiKey: string,
  defaultProjectId: string
): Promise<{ plan: StructuredAiResponse; engine: string }> {
  if (apiKey.trim()) {
    try {
      const endpoint =
        'https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=' +
        encodeURIComponent(apiKey.trim());

      const res = await fetch(endpoint, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          contents: [{ role: 'user', parts: [{ text: rawText }] }],
          systemInstruction: {
            parts: [
              {
                text: 'Zerlege den Sprachbefehl in präzise Einzelaktionen für proj-baeckerei, proj-foodtruck, proj-smarthome, proj-gewohnheiten oder proj-alltag. shortCheckableTitle strikt maximal 6 Wörter!'
              }
            ]
          },
          generationConfig: {
            responseMimeType: 'application/json',
            responseSchema: AI_ROUTER_RESPONSE_SCHEMA
          }
        })
      });

      if (res.ok) {
        const data = await res.json();
        const jsonText = data?.candidates?.[0]?.content?.parts?.[0]?.text;
        if (jsonText) {
          const parsed = JSON.parse(jsonText) as StructuredAiResponse;
          if (parsed?.actions?.length > 0) {
            return { plan: parsed, engine: 'Gemini 2.5 Flash (JSON-Schema)' };
          }
        }
      }
    } catch {
      // Automatischer Fallback auf lokalen Parser
    }
  }

  return {
    plan: buildLocalFallbackPlan(rawText, defaultProjectId),
    engine: 'Lokaler Offline-Schema-Router'
  };
}

export async function askQuickAssistantQuestion(
  question: string,
  projectName: string,
  apiKey: string,
  attachment: Attachment | null
): Promise<string> {
  if (apiKey.trim()) {
    try {
      const endpoint =
        'https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=' +
        encodeURIComponent(apiKey.trim());

      const parts: Array<Record<string, unknown>> = [
        {
          text: `Beantworte diese Praxis-Frage kompakt, technisch präzise und stichpunktartig für das Projekt "${projectName}": ${question}`
        }
      ];

      if (attachment?.type === 'image' && attachment.dataUrl?.startsWith('data:image/')) {
        parts.push({
          inlineData: {
            mimeType: attachment.mimeType || 'image/png',
            data: attachment.dataUrl.split(',')[1]
          }
        });
      }

      const res = await fetch(endpoint, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ contents: [{ role: 'user', parts }] })
      });

      if (res.ok) {
        const data = await res.json();
        const reply = data?.candidates?.[0]?.content?.parts?.[0]?.text;
        if (reply) return reply;
      }
    } catch {
      // Fallback unten
    }
  }

  return [
    `Praxis-Kurzcheck (${projectName}):`,
    `• Anfrage: „${question}“`,
    '• Prüfe im Reiter „Allgemeine Infos“ die hinterlegten Einbaumaße, Anschlusswerte und Schaltpläne.',
    '• Falls Material benötigt wird: Im Reiter „Einkaufswagen“ liefert der Beschaffungs-Check sofort den Vergleich Baumarkt vs. Online.'
  ].join('\n');
}

import React from 'react';
import { ExternalLink, Lightbulb, Store } from 'lucide-react';
import { ProcurementCheckData } from '../types';

export function buildProcurementCheck(
  title = '',
  customCheck?: ProcurementCheckData
): ProcurementCheckData {
  if (customCheck?.ideas && customCheck?.regionalVsOnline && customCheck?.searchTerm) {
    return customCheck;
  }

  const cleanSearch = title
    .replace(/\([^)]*\)/g, '')
    .replace(/\d+\s*(?:Säcke|Paar|Kartons|Stück|Packungen|Pakete|Set|x|kg|m|mm|L)\b/gi, '')
    .trim();
  const searchTerm = cleanSearch || title || 'Werkstatt Bedarf';
  const lower = title.toLowerCase();

  if (/(gas|propan|regler|schlauch|kabel|cee|verteiler)/i.test(lower)) {
    return {
      ideas:
        'Gewerbe-Ausführung mit DVGW-/VDE-Prüfzeichen wählen (+ Pflicht für Foodtruck-Abnahme & hohe Hitzebeständigkeit).',
      regionalVsOnline:
        '? Regional im Baumarkt (Bauhaus/Hornbach) direkt prüfen & sofort mitnehmen; Spezial-Gewerberegler (BGV D34) online gegenprüfen.',
      searchTerm
    };
  }

  if (/(auszug|schwerlast|shelly|eurobox|knopfzelle|cr2032|leinen)/i.test(lower)) {
    return {
      ideas:
        'Industrie-/Gastronorm-Qualität mit Rastfunktion bzw. Staffelpack wählen (+ exakte Passform für den TSA-Ausbau, deutlich günstiger pro Stück).',
      regionalVsOnline:
        '? Online bestellen – Schwerlastauszüge mit Verriegelung, Shelly-Aktoren und lebensmittelechte Pizzaballen-Boxen sind online bis zu 40 % günstiger.',
      searchTerm
    };
  }

  return {
    ideas:
      'Option A: Gewerbe-/Edelstahlausführung (CNS 1.4301) für Dauerbelastung. Option B: Standard-Ausführung für schnellen Austausch.',
    regionalVsOnline:
      '?? Bei heutigem Einbau lokal im Baumarkt holen; für geplante Baugruppen vorab Preise vergleichen.',
    searchTerm
  };
}

import React, { useState } from 'react';
import { CheckCircle2, Flame, Minus, Plus, RotateCcw } from 'lucide-react';
import { PluginContextProps, PosSoldVariety, THEME } from '../types';
import { formatNow } from '../services/storage';

const DEFAULT_VARIETIES: PosSoldVariety[] = [
  { id: 'v-marg', name: 'Margherita DOP', unitPrice: 11.5, unitCost: 2.65, count: 0 },
  { id: 'v-diav', name: 'Diavola Piccante', unitPrice: 13.5, unitCost: 3.35, count: 0 },
  { id: 'v-pros', name: 'Prosciutto & Funghi', unitPrice: 13.0, unitCost: 3.2, count: 0 },
  { id: 'v-band', name: 'Bandit Special', unitPrice: 14.5, unitCost: 3.85, count: 0 }
];

export const PosTapClickerPlugin: React.FC<PluginContextProps> = ({
  project,
  onUpdateProjectMeta,
  onRecordEventSale,
  onNotify
}) => {
  const [eventName, setEventName] = useState('Streetfood Einsatz');
  const [varieties, setVarieties] = useState<PosSoldVariety[]>(DEFAULT_VARIETIES);
  const [tipFund, setTipFund] = useState<number>(0);

  const totalPizzas = varieties.reduce((acc, v) => acc + v.count, 0);
  const grossRevenue = varieties.reduce((acc, v) => acc + v.count * v.unitPrice, 0);
  const cogsTotal = varieties.reduce((acc, v) => acc + v.count * v.unitCost, 0);
  const grossProfit = grossRevenue - cogsTotal;

  const updateCount = (id: string, delta: number) => {
    setVarieties((prev) =>
      prev.map((v) => (v.id === id ? { ...v, count: Math.max(0, v.count + delta) } : v))
    );
  };

  const handleCheckoutEvent = () => {
    if (totalPizzas === 0 && tipFund === 0) {
      onNotify('Noch keine Verkäufe oder Trinkgelder gezählt.');
      return;
    }

    const previousFund = Number(project.customMeta?.feuerwehrautoFondsGesamt || 0);
    const updatedFund = Number((previousFund + tipFund).toFixed(2));

    onRecordEventSale({
      id: `sale-${Date.now()}`,
      timestamp: formatNow(),
      eventName: eventName.trim() || 'Pizza Bandit Event',
      projectId: project.id,
      totalPizzas,
      grossRevenue,
      cogsTotal,
      grossProfit,
      firetruckTipFund: tipFund,
      items: varieties
    });

    onUpdateProjectMeta({
      letztesEventUmsatz: grossRevenue.toFixed(2),
      feuerwehrautoFondsGesamt: updatedFund
    });

    setVarieties(DEFAULT_VARIETIES);
    setTipFund(0);
    onNotify('Event-Abrechnung in Backoffice-Auswertung gespeichert!');
  };

  return (
    <div className="p-3.5 rounded-xl border border-white/10 bg-[#2F363D] space-y-3">
      <div className="flex items-center justify-between gap-2">
        <div className="flex items-center gap-2">
          <Flame className="w-4 h-4 text-[#14B8A6]" />
          <h4 className="text-xs sm:text-sm font-bold text-white">
            Live-Verkaufs-Clicker (POS)
          </h4>
        </div>
        <button
          type="button"
          onClick={() => {
            setVarieties(DEFAULT_VARIETIES);
            setTipFund(0);
          }}
          className="text-[10px] px-2 py-1 rounded bg-[#181A1B] text-[#9CA3AF] hover:text-white flex items-center gap-1"
        >
          <RotateCcw className="w-3 h-3" />
          Nullen
        </button>
      </div>

      <input
        type="text"
        value={eventName}
        onChange={(e) => setEventName(e.target.value)}
        placeholder="Event-Bezeichnung (z. B. Hafenmarkt)..."
        className="w-full px-2.5 py-1.5 rounded-lg text-xs bg-[#181A1B] text-white border border-white/10"
      />

      {/* 4 große Touch-Buttons für den Einhand-Verkauf */}
      <div className="grid grid-cols-2 gap-2">
        {varieties.map((v) => (
          <div
            key={v.id}
            className="p-2.5 rounded-xl bg-[#181A1B] border border-white/10 flex flex-col justify-between gap-2"
          >
            <div>
              <span className="text-xs font-bold text-white block truncate">{v.name}</span>
              <span className="text-[10px] font-mono text-[#9CA3AF]">
                VK {v.unitPrice.toFixed(2)} € • WE {v.unitCost.toFixed(2)} €
              </span>
            </div>

            <div className="flex items-center justify-between gap-1 pt-1">
              <button
                type="button"
                onClick={() => updateCount(v.id, -1)}
                className="w-7 h-7 rounded-lg bg-[#24292E] text-[#9CA3AF] hover:text-white flex items-center justify-center border border-white/10"
              >
                <Minus className="w-3.5 h-3.5" />
              </button>
              <span className="text-base font-mono font-bold text-[#14B8A6]">{v.count}</span>
              <button
                type="button"
                onClick={() => updateCount(v.id, 1)}
                className="px-3 h-8 rounded-lg text-white font-bold text-xs flex items-center gap-1 shadow active:scale-95 transition"
                style={{ backgroundColor: THEME.accentPrimary }}
              >

import React, { useMemo, useState } from 'react';
import { Calculator, ShoppingCart } from 'lucide-react';
import { PluginContextProps, THEME } from '../types';

export const EventQuantityCalcPlugin: React.FC<PluginContextProps> = ({
  onAddCartItems,
  onUpdateProjectMeta,
  onNotify
}) => {
  const [visitors, setVisitors] = useState('350');
  const [conversionPct, setConversionPct] = useState('35');
  const [ballWeightG, setBallWeightG] = useState('265');
  const [hydrationPct, setHydrationPct] = useState('68');
  const [safetyBufferPct, setSafetyBufferPct] = useState('12');

  const calc = useMemo(() => {
    const vis = Math.max(0, Number(visitors) || 0);
    const conv = Math.max(1, Number(conversionPct) || 0) / 100;
    const buffer = 1 + Math.max(0, Number(safetyBufferPct) || 0) / 100;
    const weight = Math.max(150, Number(ballWeightG) || 265);
    const hyd = Math.max(50, Number(hydrationPct) || 68) / 100;

    const targetBalls = Math.ceil(vis * conv * buffer);
    const totalDoughG = targetBalls * weight;
    // Mehl + Wasser (hyd) + Salz (2.8%) + Hefe (0.2%) = 1 + hyd + 0.03
    const flourKg = totalDoughG / (1 + hyd + 0.03) / 1000;
    const waterL = (flourKg * hyd);
    const sugoKg = (targetBalls * 85) / 1000;
    const fiorDiLatteKg = (targetBalls * 95) / 1000;
    const euroBoxesNeeded = Math.ceil(targetBalls / 12);

    return {
      targetBalls,
      flourKg,
      waterL,
      sugoKg,
      fiorDiLatteKg,
      euroBoxesNeeded
    };
  }, [visitors, conversionPct, ballWeightG, hydrationPct, safetyBufferPct]);

  const transferIngredientsToCart = () => {
    onAddCartItems([
      {
        title: 'Pizzamehl Caputo Cuoco / Tipo 00',
        quantity: `${Math.ceil(calc.flourKg)} kg`,
        reason: `Event-Kalkulator (${calc.targetBalls} Teigballen)`
      },
      {
        title: 'San Marzano Tomaten DOP für Sugo',
        quantity: `${calc.sugoKg.toFixed(1)} kg`,
        reason: `Event-Kalkulator (${calc.targetBalls} Pizzen)`
      },
      {
        title: 'Fior di Latte Mozzarella (Schnittfest)',
        quantity: `${calc.fiorDiLatteKg.toFixed(1)} kg`,
        reason: `Event-Kalkulator (${calc.targetBalls} Pizzen)`
      }
    ]);

    onUpdateProjectMeta({
      geplanteTeigballen: calc.targetBalls,
      benoetigteEuroboxen: calc.euroBoxesNeeded
    });

    onNotify(`${calc.targetBalls} Ballen berechnet & Rohstoffe in Einkaufswagen gelegt!`);
  };

  return (
    <div className="p-3.5 rounded-xl border border-white/10 bg-[#2F363D] space-y-3">
      <div className="flex items-center gap-2">
        <Calculator className="w-4 h-4 text-[#14B8A6]" />
        <h4 className="text-xs sm:text-sm font-bold text-white">
          Besucher- &amp; Teigballen-Kalkulator
        </h4>
      </div>

      <div className="grid grid-cols-2 sm:grid-cols-3 gap-2 text-xs">
        <div>
          <label className="text-[10px] text-[#9CA3AF] block">Erw. Besucher</label>
          <input
            type="number"
            value={visitors}
            onChange={(e) => setVisitors(e.target.value)}
            className="w-full px-2 py-1.5 rounded bg-[#181A1B] text-white font-mono border border-white/10"
          />
        </div>
        <div>
          <label className="text-[10px] text-[#9CA3AF] block">Kaufquote (%)</label>
          <input
            type="number"
            value={conversionPct}
            onChange={(e) => setConversionPct(e.target.value)}

import React, { useRef, useState } from 'react';
import { HelpCircle, Loader2, Mic, MicOff, Sparkles, Upload, X } from 'lucide-react';
import { Attachment, THEME } from '../types';
import { DEMO_VOICE_COMMANDS } from '../services/aiRouter';

interface VoiceModalProps {
  open: boolean;
  activeProjectName: string;
  onClose: () => void;
  onDistributeCommand: (text: string, attachment: Attachment | null) => Promise<void>;
  onAskQuickQuestion: (
    text: string,
    attachment: Attachment | null
  ) => Promise<{ answer: string }>;
  onSaveAnswerToInfos: (question: string, answer: string, attachment: Attachment | null) => void;
}

export const VoiceModal: React.FC<VoiceModalProps> = ({
  open,
  activeProjectName,
  onClose,
  onDistributeCommand,
  onAskQuickQuestion,
  onSaveAnswerToInfos
}) => {
  const [mode, setMode] = useState<'distribute' | 'question'>('distribute');
  const [transcript, setTranscript] = useState('');
  const [isListening, setIsListening] = useState(false);
  const [isProcessing, setIsProcessing] = useState(false);
  const [speechNotice, setSpeechNotice] = useState('');
  const [attachment, setAttachment] = useState<Attachment | null>(null);
  const [qaReply, setQaReply] = useState<string | null>(null);
  const recognitionRef = useRef<any>(null);

  if (!open) return null;

  const toggleMic = () => {
    if (isListening && recognitionRef.current) {
      try {
        recognitionRef.current.stop();
      } catch {
        // ignore
      }
      setIsListening(false);
      return;
    }

    setSpeechNotice('');
    const SpeechRec =
      (window as any).SpeechRecognition || (window as any).webkitSpeechRecognition;

    if (!SpeechRec) {
      setSpeechNotice('Web Speech API im aktuellen Browser nicht verfügbar – nutze Texteingabe oder Demo-Befehle.');
      return;
    }

    try {
      const rec = new SpeechRec();
      rec.lang = 'de-DE';
      rec.continuous = true;
      rec.interimResults = true;
      rec.onstart = () => setIsListening(true);
      rec.onresult = (ev: any) => {
        let chunk = '';
        for (let i = ev.resultIndex; i < ev.results.length; i++) {
          if (ev.results[i].isFinal) {
            chunk += ev.results[i][0].transcript + ' ';
          }
        }
        if (chunk.trim()) {
          setTranscript((prev) => (prev ? `${prev.trim()} ${chunk.trim()}` : chunk.trim()));
        }
      };
      rec.onerror = () => {
        setIsListening(false);
        setSpeechNotice('Mikrofonzugriff blockiert – wähle unten einen Demo-Befehl oder tippe direkt.');
      };
      rec.onend = () => setIsListening(false);
      recognitionRef.current = rec;
      rec.start();
    } catch {
      setIsListening(false);
    }
  };

  const handleFileChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    const file = e.target.files?.[0];
    if (!file) return;
    const sizeKB = `${Math.max(1, Math.round(file.size / 1024))} KB`;
    const isImage = file.type.startsWith('image/');
    const isPdf = file.type === 'application/pdf' || file.name.toLowerCase().endsWith('.pdf');
    const isText = file.type.startsWith('text/') || /\.(txt|md|json|csv)$/i.test(file.name);

    const reader = new FileReader();
    reader.onload = (ev) => {
      const res = ev.target?.result;
      setAttachment({
        id: `att-voice-${Date.now()}`,
        name: file.name,
        type: isImage ? 'image' : isPdf ? 'pdf' : 'text',
        mimeType: file.type || 'application/octet-stream',
        size: sizeKB,
        dataUrl: isImage || isPdf ? String(res) : null,
        textContent: isText ? String(res) : null
      });
    };

    if (isText && !isImage && !isPdf) reader.readAsText(file);
    else reader.readAsDataURL(file);
    e.target.value = '';
  };

  const handleExecute = async () => {
    if (!transcript.trim()) return;
    setIsProcessing(true);
    if (mode === 'distribute') {
      await onDistributeCommand(transcript.trim(), attachment);
      setTranscript('');
      setAttachment(null);
      setIsProcessing(false);
      onClose();
    } else {
      const res = await onAskQuickQuestion(transcript.trim(), attachment);
      setQaReply(res.answer);
      setIsProcessing(false);
    }
  };

  return (
    <div className="fixed inset-0 z-50 bg-black/80 backdrop-blur-sm flex items-center justify-center p-4 overflow-y-auto">
      <div
        className="max-w-lg w-full rounded-2xl border border-white/15 overflow-hidden shadow-2xl"
        style={{ backgroundColor: THEME.bgCard }}
      >
        <div className="px-5 py-4 border-b border-white/10 flex items-center justify-between">
          <div className="flex items-center gap-2.5">
            <div
              className="w-9 h-9 rounded-xl flex items-center justify-center text-white"
              style={{ backgroundColor: THEME.accentPrimary }}
            >
              <Mic className="w-5 h-5" />
            </div>
            <div>
              <div className="flex items-center gap-2">
                <h3 className="text-sm font-bold text-white">Sprach- &amp; KI-Zentrale</h3>
                <span className="text-[10px] font-mono px-2 py-0.5 rounded bg-[#2F363D] text-[#14B8A6]">
                  Alt + S
                </span>
              </div>
              <p className="text-[11px] text-[#9CA3AF]">
                Verteilt Aufträge projektübergreifend &amp; speichert Anhänge lokal in IndexedDB.
              </p>
            </div>
          </div>
          <button onClick={onClose} className="p-1 text-[#9CA3AF] hover:text-white">
            <X className="w-5 h-5" />
          </button>
        </div>

        <div className="p-5 space-y-3.5 max-h-[82vh] overflow-y-auto">
          <div className="grid grid-cols-2 gap-2 p-1 rounded-xl bg-[#181A1B] border border-white/10">
            <button
              type="button"
              onClick={() => {
                setMode('distribute');
                setQaReply(null);
              }}
              className={`py-2 px-3 rounded-lg text-xs font-bold flex items-center justify-center gap-1.5 transition ${
                mode === 'distribute'
                  ? 'bg-[#0A9396] text-white shadow'
                  : 'text-[#9CA3AF] hover:text-white'
              }`}
            >
              <Sparkles className="w-3.5 h-3.5" />
              Verteilen &amp; Einsortieren
            </button>
            <button
              type="button"
              onClick={() => setMode('question')}
              className={`py-2 px-3 rounded-lg text-xs font-bold flex items-center justify-center gap-1.5 transition ${
                mode === 'question'
                  ? 'bg-[#0A9396] text-white shadow'
                  : 'text-[#9CA3AF] hover:text-white'
              }`}
            >
              <HelpCircle className="w-3.5 h-3.5" />
              Schnell-Frage / Foto
            </button>
          </div>

          <div className="flex flex-col sm:flex-row gap-2">
            <button
              type="button"
              onClick={toggleMic}
              className="flex-1 py-2.5 px-3 rounded-xl text-xs font-semibold text-white flex items-center justify-center gap-2"
              style={{ backgroundColor: isListening ? '#DC2626' : THEME.accentPrimary }}
            >
              {isListening ? <MicOff className="w-4 h-4" /> : <Mic className="w-4 h-4" />}
              {isListening ? 'Aufnahme stoppen' : 'Live-Mikrofon starten (de-DE)'}
            </button>

            <label
              className="cursor-pointer py-2.5 px-3 rounded-xl text-xs font-medium border border-white/15 flex items-center justify-center gap-1.5 text-white"
              style={{ backgroundColor: THEME.bgSub }}
            >
              <Upload className="w-3.5 h-3.5 text-[#14B8A6]" />
              <span className="truncate max-w-[140px]">
                {attachment ? attachment.name : 'Foto / PDF / Text'}
              </span>
              <input
                type="file"
                accept="image/*,.pdf,.txt,.md"
                className="hidden"
                onChange={handleFileChange}
              />
            </label>
          </div>

          {speechNotice && (
            <p className="text-[11px] text-[#14B8A6] bg-[#181A1B] p-2 rounded-lg border border-[#14B8A6]/30">
              {speechNotice}
            </p>
          )}

          {mode === 'distribute' && (
            <div className="p-2.5 rounded-xl bg-[#181A1B] border border-white/10 space-y-1.5">
              <span className="text-[10px] font-bold text-[#14B8A6] uppercase block">
                1-Klick Demo-Sprachbefehle:
              </span>
              {DEMO_VOICE_COMMANDS.map((cmd) => (
                <button
                  key={cmd.id}
                  type="button"
                  onClick={() => setTranscript(cmd.text)}
                  className="w-full text-left p-2 rounded-lg bg-[#24292E] hover:border-[#14B8A6] border border-white/10 transition"
                >
                  <div className="text-[11px] font-bold text-[#14B8A6]">{cmd.label}</div>
                  <div className="text-[10px] text-[#9CA3AF] truncate mt-0.5">„{cmd.text}“</div>
                </button>
              ))}
            </div>
          )}

          <textarea
            rows={3}
            value={transcript}
            onChange={(e) => setTranscript(e.target.value)}
            placeholder="Sprich oder tippe deinen Kombi-Befehl oder deine Praxis-Frage ein..."
            className="w-full p-3 rounded-xl text-xs bg-[#181A1B] text-white border border-white/15 focus:outline-none focus:border-[#14B8A6]"
          />

          {qaReply && (
            <div className="p-3 rounded-xl bg-[#181A1B] border border-[#14B8A6] space-y-2">
              <div className="text-xs whitespace-pre-line text-white leading-relaxed">
                {qaReply}
              </div>
              <button
                type="button"
                onClick={() => {
                  onSaveAnswerToInfos(transcript, qaReply, attachment);
                  setQaReply(null);
                  setTranscript('');
                  setAttachment(null);
                  onClose();
                }}
                className="px-3 py-1.5 rounded-lg text-xs font-semibold text-white"
                style={{ backgroundColor: THEME.accentPrimary }}
              >
                In „{activeProjectName} – Allgemeine Infos“ speichern
              </button>
            </div>
          )}

          <div className="flex justify-end gap-2 pt-2 border-t border-white/10">
            <button onClick={onClose} className="px-3 py-1.5 text-xs text-[#9CA3AF]">
              Schließen
            </button>
            <button
              onClick={handleExecute}
              disabled={!transcript.trim() || isProcessing}
              className="px-4 py-2 rounded-xl text-xs font-semibold text-white flex items-center gap-1.5 disabled:opacity-40"
              style={{ backgroundColor: THEME.accentPrimary }}
            >
              {isProcessing ? (
                <Loader2 className="w-4 h-4 animate-spin" />
              ) : (
                <Sparkles className="w-4 h-4" />
              )}
              <span>{mode === 'distribute' ? 'Jetzt einsortieren' : 'Frage auswerten'}</span>
            </button>
          </div>
        </div>
      </div>
    </div>
  );
};

                  </div>
                ) : (
                  activePlugins.map((plugin) => (

};

import React, { useEffect, useMemo, useState } from 'react';
import {

  Attachment,
  BackofficeTabId,
  DomainType,

  downloadStateBackupJson,

  loadPersistedState,
  savePersistedState

export default function App() {
  const [state, setState] = useState<AppStateSnapshot>(INITIAL_APP_SNAPSHOT);
  const [hydrated, setHydrated] = useState(false);

  // Navigation & URL ?mode=cover Erkennung
  const [isBackoffice, setIsBackoffice] = useState(false);
  const [backofficeTab, setBackofficeTab] = useState<BackofficeTabId>('analytics');
  const [flip7CoverMode, setFlip7CoverMode] = useState<boolean>(() => {
    if (typeof window === 'undefined') return false;
    return new URLSearchParams(window.location.search).get('mode') === 'cover';
  });

  const [activeDomain, setActiveDomain] = useState<DomainType>('arbeit');
  const [selectedProjectId, setSelectedProjectId] = useState<string>('proj-foodtruck');
  const [activeProjectTab, setActiveProjectTab] = useState<ProjectTabId>('tasks');
  const [highlightedItemId, setHighlightedItemId] = useState<string | null>(null);

  // Modals & Toast
  const [voiceModalOpen, setVoiceModalOpen] = useState(false);
  const [realityModalOpen, setRealityModalOpen] = useState(false);
  const [selfCheckModalOpen, setSelfCheckModalOpen] = useState(false);
  const [previewAttachment, setPreviewAttachment] = useState<Attachment | null>(null);
  const [newProjectModalOpen, setNewProjectModalOpen] = useState(false);
  const [newProjName, setNewProjName] = useState('');
  const [newProjSubtitle, setNewProjSubtitle] = useState('');
  const [toast, setToast] = useState<string | null>(null);

  const notify = (msg: string) => {
    setToast(msg);
    setTimeout(() => setToast(null), 3400);
  };

  // Initiales Laden aus IndexedDB
  useEffect(() => {
    loadPersistedState(INITIAL_APP_SNAPSHOT).then((loaded) => {
      setState(loaded);
      setHydrated(true);
    });
  }, []);

  // Automatische Speicherung in IndexedDB nach Hydration
  useEffect(() => {
    if (!hydrated) return;
    savePersistedState(state);
  }, [state, hydrated]);

  // URL-Parameter ?mode=cover sauber synchron halten
  const toggleCoverMode = (enable: boolean) => {
    setFlip7CoverMode(enable);
    try {
      const url = new URL(window.location.href);
      if (enable) url.searchParams.set('mode', 'cover');
      else url.searchParams.delete('mode');
      window.history.replaceState({}, '', url.toString());
    } catch {
      // ignore in restricted environments
    }
  };

  // Globaler Alt + S Shortcut
  useEffect(() => {
    const onKey = (e: KeyboardEvent) => {
      if (e.altKey && (e.key === 's' || e.key === 'S')) {
        e.preventDefault();
        setVoiceModalOpen((v) => !v);
      }
    };
    window.addEventListener('keydown', onKey);
    return () => window.removeEventListener('keydown', onKey);
  }, []);

  const domainProjects = useMemo(
    () => state.projects.filter((p) => !p.archived && p.domain === activeDomain),
    [state.projects, activeDomain]
  );

  const activeProject = useMemo(() => {
    return (
      domainProjects.find((p) => p.id === selectedProjectId) ||
      domainProjects[0] ||
      state.projects.find((p) => !p.archived)
    );
  }, [domainProjects, selectedProjectId, state.projects]);

  const topThreeOpenTasks = useMemo(() => {
    const out: Array<{ projectId: string; projectName: string; task: Project['tasks'][0] }> = [];
    if (activeProject) {
      activeProject.tasks.forEach((t) => {
        if (!t.completed) out.push({ projectId: activeProject.id, projectName: activeProject.name, task: t });
      });
    }
    state.projects.forEach((p) => {
      if (p.archived || p.id === activeProject?.id) return;
      p.tasks.forEach((t) => {
        if (!t.completed) out.push({ projectId: p.id, projectName: p.name, task: t });
      });
    });
    return out.slice(0, 3);
  }, [state.projects, activeProject]);

  // Projekt-Mutationen
  const updateProject = (projectId: string, updater: (p: Project) => Project) => {
    setState((prev) => ({
      ...prev,
      projects: prev.projects.map((p) => (p.id === projectId ? updater(p) : p))
    }));
  };

  const handleDistributeVoiceCommand = async (
    rawText: string,
    attachment: Attachment | null
  ) => {
    const { plan, engine } = await routeVoiceCommand(
      rawText,
      state.userApiKey,
      activeProject?.id || 'proj-foodtruck'
    );
    const timestamp = formatNow();
    const executedActions: AiExecutedAction[] = [];
    let firstProjId = selectedProjectId;
    let firstTab: ProjectTabId = activeProjectTab;

    setState((prev) => {
      const nextProjects: Project[] = JSON.parse(JSON.stringify(prev.projects));

      plan.actions.forEach((act, idx) => {
        const target =
          nextProjects.find((p) => p.id === act.targetProjectId) || nextProjects[0];
        if (idx === 0) firstProjId = target.id;

        const safeTitle = enforceMaxSixWords(act.shortCheckableTitle, 'Neuer KI-Punkt');
        const safeNote = enforceMaxSixWords(act.changeFooterNote, 'Per KI einsortiert');
        const itemId = `ai-${Date.now()}-${idx}`;

        if (act.actionType === 'ADD_CART_ITEM') {
          if (idx === 0) firstTab = 'cart';
          target.cart.unshift({
            id: itemId,
            title: safeTitle,
            quantity: act.quantityOrMeasure || '1x',
            price: act.estimatedPrice || '',
            completed: false,
            aiTouched: true,
            lastModified: timestamp,
            changeReason: safeNote,
            source: 'KI-Zuordnung',
            procurementCheck: buildProcurementCheck(safeTitle),
            customMeta: { detail: act.detailedExplanation }
          });
          executedActions.push({
            actionId: `act-${Date.now()}-${idx}`,
            actionType: act.actionType,
            targetProjectId: target.id,
            targetSubTab: 'cart',
            targetItemId: itemId,
            shortCheckableTitle: safeTitle,
            detailedExplanation: act.detailedExplanation,
            changeFooterNote: safeNote,
            undone: false
          });
        } else if (act.actionType === 'UPDATE_EXPLANATION') {
          if (idx === 0) firstTab = 'explanations';
          target.explanations.unshift({
            id: itemId,
            title: safeTitle,
            stepsText: act.detailedExplanation,
            lastModified: timestamp,
            changeReason: safeNote,
            source: 'KI-Zuordnung',
            aiTouched: true,
            customMeta: {}
          });
          executedActions.push({
            actionId: `act-${Date.now()}-${idx}`,
            actionType: act.actionType,
            targetProjectId: target.id,
            targetSubTab: 'explanations',
            targetItemId: itemId,
            shortCheckableTitle: safeTitle,
            detailedExplanation: act.detailedExplanation,
            changeFooterNote: safeNote,
            undone: false
          });
        } else if (act.actionType === 'ADD_INFO') {
          if (idx === 0) firstTab = 'infos';
          target.infos.unshift({
            id: itemId,
            title: safeTitle,
            content: act.detailedExplanation,
            attachments: attachment ? [attachment] : [],
            lastModified: timestamp,
            changeReason: safeNote,
            source: 'KI-Zuordnung',
            aiTouched: true,
            customMeta: {}
          });
          executedActions.push({
            actionId: `act-${Date.now()}-${idx}`,
            actionType: act.actionType,
            targetProjectId: target.id,
            targetSubTab: 'infos',
            targetItemId: itemId,
            shortCheckableTitle: safeTitle,
            detailedExplanation: act.detailedExplanation,
            changeFooterNote: safeNote,
            undone: false
          });
        } else {
          if (idx === 0) firstTab = 'tasks';
          target.tasks.unshift({
            id: itemId,
            title: safeTitle,
            completed: act.actionType === 'CHECK_OFF_TASK',
            priority: act.priority || 'Mittel',
            estimatedMinutes: act.estimatedMinutes || 25,
            dayBlock: null,
            reminderAt: '',
            aiTouched: true,
            lastModified: timestamp,
            changeReason: safeNote,
            source: 'KI-Zuordnung',
            customMeta: { detail: act.detailedExplanation }
          });
          executedActions.push({
            actionId: `act-${Date.now()}-${idx}`,
            actionType: act.actionType,
            targetProjectId: target.id,
            targetSubTab: 'tasks',
            targetItemId: itemId,
            shortCheckableTitle: safeTitle,
            detailedExplanation: act.detailedExplanation,
            changeFooterNote: safeNote,
            undone: false
          });
        }
      });

      const newLog: AiLogEntry = {
        id: `log-${Date.now()}`,
        timestamp,
        rawInput: rawText,
        summary: plan.summary,
        engine,
        undone: false,
        actions: executedActions
      };

      return {
        ...prev,
        projects: nextProjects,
        aiLogs: [newLog, ...prev.aiLogs]
      };
    });

    const dest = state.projects.find((p) => p.id === firstProjId);
    if (dest) {
      setActiveDomain(dest.domain);
      setSelectedProjectId(dest.id);
      setActiveProjectTab(firstTab);
    }
    notify(`KI-Router: ${executedActions.length} Aktion(en) einsortiert!`);
  };

  if (flip7CoverMode) {
    return (
      <>
        <Flip7CoverView
          activeProject={activeProject}
          topTasks={topThreeOpenTasks}
          onToggleTask={(projId, taskId) => {
            const ts = formatNow();
            updateProject(projId, (p) => ({
              ...p,
              tasks: p.tasks.map((t) =>
                t.id === taskId ? { ...t, completed: !t.completed, lastModified: ts } : t
              )
            }));
          }}
          onOpenVoice={() => setVoiceModalOpen(true)}
          onExitCoverMode={() => toggleCoverMode(false)}
        />
        <VoiceModal
          open={voiceModalOpen}
          activeProjectName={activeProject?.name || 'Pizza Bandit'}

          onDistributeCommand={handleDistributeVoiceCommand}
          onAskQuickQuestion={async (q, att) => ({
            answer: await askQuickAssistantQuestion(
              q,
              activeProject?.name || 'Pizza Bandit',
              state.userApiKey,
              att
            )
          })}
          onSaveAnswerToInfos={(q, ans, att) => {
            if (!activeProject) return;
            updateProject(activeProject.id, (p) => ({
              ...p,
              infos: [
                {
                  id: `i-qa-${Date.now()}`,
                  title: enforceMaxSixWords(q, 'KI-Schnellfrage'),
                  content: `Frage: ${q}\n\nAntwort:\n${ans}`,
                  attachments: att ? [att] : [],
                  lastModified: formatNow(),
                  changeReason: 'Aus Schnell-Frage gespeichert',
                  source: 'KI-Zuordnung',
                  aiTouched: true,
                  customMeta: {}
                },
                ...p.infos
              ]
            }));
            notify('Antwort unter Infos gespeichert!');
          }}
        />
      </>
    );
  }

  return (
    <div
      className="min-h-screen flex flex-col selection:bg-[#0A9396] selection:text-white"
      style={{ backgroundColor: THEME.bgMain, color: THEME.textMain }}
    >
      {/* Header */}

                  src={previewAttachment.dataUrl}
                  alt={previewAttachment.name}
                  className="max-h-[65vh] mx-auto rounded-lg"
                />
              )}
              {previewAttachment.type === 'pdf' && previewAttachment.dataUrl && (
                <iframe
                  src={previewAttachment.dataUrl}
                  title={previewAttachment.name}
                  className="w-full h-[65vh] rounded-lg border border-white/10"
                />
              )}
              {previewAttachment.type === 'text' && (
                <pre className="p-3 rounded-lg bg-[#181A1B] text-xs font-mono text-white whitespace-pre-wrap">
                  {previewAttachment.textContent || 'Kein Textinhalt.'}
                </pre>
              )}
            </div>
          </div>
        </div>
      )}

      {/* Toast-Feedback */}
      {toast && (
        <div className="fixed top-16 left-1/2 -translate-x-1/2 z-50 px-4 py-2 rounded-full bg-[#0A9396] text-white text-xs font-bold shadow-2xl flex items-center gap-2 border border-[#14B8A6]">
          <CheckCircle2 className="w-4 h-4 shrink-0" />
          <span>{toast}</span>
        </div>
      )}
    </div>
  );
}
